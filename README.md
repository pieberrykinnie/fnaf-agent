# fnaf-agent

AI agent that plays Five Nights at Freddy's 1 via screen capture (OpenCV) and synthetic input, with an RL stretch goal (Stable-Baselines3).

- `PLAN.md` — development plan and architecture
- `CLAUDE.md` — conventions and verification protocol for Claude Code
- `BACKLOG.md` — ordered task queue

Setup: run `scripts/bootstrap.ps1` once, then `uv run pytest`.
